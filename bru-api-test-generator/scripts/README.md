# QA Script Bundle

This directory is synchronized by `bruno-api-test-generator scripts sync`.
Do not edit copied project scripts except for an explicitly owned extension.

| Script | Purpose |
| --- | --- |
| `bruno_api_test_generator.py` | Public `init/generate/materialize/check/run/preflight/reconcile/aggregate/worker-*/scripts` entry point |
| `parse_openapi.py` | Parse offline OpenAPI and incrementally generate module contracts and cases |
| `source_constraints.py` | Extract source/response constraints and reuse local environment templates |
| `analyze_source_logic.py` | Scan cross-language API logic evidence |
| `analyze_java_logic.py` | Trace Java/Spring Controller-to-service call chains |
| `materialize_missing_bru.py` | Generate or verify registered `.bru` requests |
| `qa_constraints.py` | Enforce shared lifecycle rules and Git-backed worker boundaries |
| `check_api_coverage.py` | Reconcile OpenAPI, cases, requests, assertions, source, and evidence |
| `run_bruno.py` | Execute all modules or one module and retain result/evidence artifacts |
| `runtime_preflight.py` | Validate environment, fixtures, contract fingerprint, CLI, and route reachability |
| `normalize_bruno_report.py` | Normalize and redact raw Bruno reports |
| `validate_flow_execution.py` | Validate explicit flows, captures, and cleanup |
| `check_version_compatibility.py` | Validate the business-source version lock |
| `command_execution.py` | Resolve cross-platform commands, including Windows `.cmd` and `.bat` files |
| `qa_lock.py` | Validate OpenAPI, module, case, and generation-state fingerprints |
| `check_artifact_safety.py` | Detect credentials, JWTs, cookies, and credential-bearing URLs |
| `scripts_manager.py` | Synchronize scripts and verify version/source/SHA metadata |
| `execution_config.py` | Manage execution configuration, environments, Headers, and collection injection |

Use `worker-start` and `worker-check` around delegated module work. Use
`aggregate` after module runs to produce coordinator-owned global evidence and
the result-first global report.

`scripts-version.yaml` is generated by the synchronization command and records
skill/script versions, source, aggregate SHA, per-file SHA, and sync time.
